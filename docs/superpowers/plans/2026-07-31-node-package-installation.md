# 本地节点包安装与原子回滚

## 目标

在现有清单发现、兼容性检查、启停和版本锁定之上，补齐个人开发者可直接使用的本地节点包管理闭环。节点包仍是受信任 Python 代码，不扩张为在线市场或依赖安装器。

## API

- `POST /api/node-packages/install?filename=<name>.zip`
  - 请求体：`application/zip`
  - 成功：动作、激活包摘要、最新包扫描
  - 失败：`detail.code`、中文 `detail.message` 和可选工作流引用
- `DELETE /api/node-packages/{package_id}`
  - 仅允许安装器管理的包
  - 有工作流引用时返回 `409`
- `GET /api/node-packages/{package_id}/revisions`
  - 返回按归档时间倒序排列的历史修订
- `POST /api/node-packages/{package_id}/revisions/{revision_id}/activate`
  - 重新预检并激活指定修订，当前版本同时归档

## 后续边界

- pip 依赖仍只做预检，不由应用修改 Python 环境。
- 尚未提供签名、在线仓库、远程下载和代码沙箱。
- 历史修订是本地完整性校验，不是发布者签名或代码安全证明。

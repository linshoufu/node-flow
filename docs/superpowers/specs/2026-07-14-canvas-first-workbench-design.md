# 画布优先工作台设计

## 目标

把 Node Flow 的主编辑界面从固定多面板布局整理为画布优先的工作台。用户在日常编辑时能持续看见完整流程；运行报告、节点配置和工作流管理只在需要时占用空间。

这一阶段只调整编辑器体验和前端状态边界，不改变工作流 JSON、Python 节点契约、运行器或 API 路由。

## 已确认的范围

- 画布是桌面端的主区域。
- 运行结果使用可折叠的底部抽屉。
- 当前工作流入口必须说明当前对象和保存状态，不能只显示工作流数量。
- 加载已保存工作流或应用模板后，画布自动适应全部根流程节点。
- 配置面板在未选择节点时收为安静的窄态提示。
- 移动端保持纵向顺序布局，不实现拖拽分屏或面板尺寸持久化。

## 工作台结构

桌面端保持“节点库 - 画布 - 配置”三栏，但画布获得剩余高度；运行结果不再始终占据工作区的一行。

```text
顶栏：工作流上下文 | 工作流入口 | 验证 | 保存 | 运行
主区：节点库         | 画布       | 配置面板
底部：运行结果抽屉（默认收起）
```

### 顶栏和工作流入口

顶栏展示当前工作流名称、草稿/已保存/未保存状态。工作流管理触发器使用当前工作流名称；没有已保存工作流时显示“工作流”。触发器附带已保存工作流数作为次要信息，不把数字作为唯一内容。

新建、复制、搜索、运行历史和工作流列表继续位于工作流管理弹层。验证、保存和运行保留在顶栏，因为它们是当前编辑循环中最常用的命令。节点升级检查、取消运行等次要命令保持现有可发现性，但不增加新的常驻文字按钮。

### 运行结果抽屉

运行结果由 `expanded` 和 `manuallyPinned` 两个前端状态驱动：

- 初始和无运行记录时收起，只展示一条高度固定的摘要栏。
- 创建新运行后自动展开。
- 当前运行进入 `failed`、`cancelled` 或返回运行错误时自动展开。
- 用户手动展开或收起后，当前运行期间不再被自动改变，避免轮询时界面跳动。
- 切换工作流、新建草稿、应用模板或清空当前运行视图时，抽屉恢复收起且取消手动固定状态。

收起摘要栏显示中文运行状态、最近运行的简短结果，以及展开/收起图标按钮。展开后保留现有测试报告、执行数据和运行事件三个标签及节点运行详情，不丢失当前选中的标签或筛选条件。

### 画布适应和配置面板

`FlowCanvas` 暴露一个由上层递增的 `fitRequestKey`。当加载已保存工作流、应用模板、从历史运行返回当前流程或切换根流程时，上层递增该值；画布在节点渲染完成后的下一帧调用 React Flow 的 `fitView`。用户拖动、缩放和编辑节点时不触发适应，避免干扰工作。

未选中节点时，配置面板采用窄态：保留“配置”标题和一句短提示，不显示大段空白说明。选中节点后恢复现有完整配置与运行详情。面板宽度保持稳定，避免选择节点时画布发生横向跳动。

## 组件边界

- `apps/web/src/lib/workbenchLayout.ts`：纯函数，决定运行抽屉的初始、自动和手动展开状态，并提供摘要文案数据。
- `apps/web/src/components/RunDrawer.tsx`：只负责摘要栏、展开按钮和展开容器；内部复用现有 `RunPanel`。
- `apps/web/src/components/WorkflowManager.tsx`：只负责将触发器文案改为当前工作流上下文；管理功能不重新实现。
- `apps/web/src/components/FlowCanvas.tsx`：只消费 `fitRequestKey`，不拥有业务加载状态。
- `apps/web/src/App.tsx`：拥有工作台状态，向抽屉、管理入口和画布传入最小属性。

不把抽屉状态写入 `WorkflowDocument.settings`，因为它是本地界面偏好而不是工作流可执行定义。

## 异常和兼容性

- 没有当前运行时，摘要栏显示“暂无运行结果”，展开后继续显示当前空状态。
- 历史运行视图也可展开抽屉；清除历史视图后回到当前运行摘要。
- `fitView` 失败、没有节点或 React Flow 尚未初始化时静默跳过，不修改工作流位置。
- 旧工作流与模板无需迁移。

## 验收与测试

- `workbenchLayout` 单元测试覆盖初始收起、运行自动展开、失败自动展开、手动固定和重置。
- `RunDrawer` 组件测试覆盖中文摘要、按钮可访问名称、展开后渲染 `RunPanel`。
- `WorkflowManager` 测试验证触发器显示当前工作流名称和数量。
- `FlowCanvas` 测试验证 `fitRequestKey` 变化时请求适应视图，普通节点编辑不请求。
- `App` 测试验证加载工作流和使用模板后递增适应请求，创建运行后展开抽屉。
- 浏览器冒烟验证桌面与窄屏：加载模板、拖动画布、收起/展开运行结果、运行失败后自动展开、切换工作流后恢复收起。

## 非目标

- 不做可拖拽分屏、面板宽高持久化或多窗口布局。
- 不改变节点端口、连接校验、运行事件格式和运行器语义。
- 不增加认证、协作、触发器、凭据或节点市场能力。
